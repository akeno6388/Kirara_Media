# Kirara_Media

> 一款 Kirara Media 的手机客户端，让你在手机上畅快观看媒体、参与议题讨论、与好友互动。
> 通过 **KIRARA 通行证登录 → 链接令牌 → 打开媒体页** 三步，一次配置，之后自动登录、免密直达。

## ✨ 功能特性

- 🔐 **一次登录，长期免密**：登录一次通行证，之后每次打开软件自动进入，无需反复输入账号密码
- 🔑 **令牌管理器**：集中保管你的媒体账户令牌，支持手动录入与扫码导入；令牌加密保存，仅本机可读
- 📷 **扫码导入令牌**：配合桌面端「令牌管理器」的扫码出码，手机相机扫码即可将令牌安全导入；桌面端二维码每 15 秒自动更新，令牌经加密传输，仅属主账户可导入；相机权限被拒时可一键跳转系统设置开启，系统返回键可直接退出扫码页
- 🖥️ **媒体随行**：在手机上完整使用 Kirara Media —— 浏览片库、查看详情、观看视频，画面与操作与电脑端一致
- 🎬 **沉浸式横屏播放**：播放视频时旋转为横屏会自动进入全屏并收起系统栏；全屏期间双击 / 误触不会退出全屏，按系统返回键 = 退出全屏但**视频继续播放**（不暂停）；离开媒体页自动暂停播放，切回不会自动续播
- 🤖 **自动登录**：打开媒体页自动完成登录；已登录时智能跳过，遇到问题会说明原因并可一键重试，也可随时手动登录
- 💬 **议题评论**：视频详情页一键打开评论区，支持发表评论、回复、点赞与 @好友；与电脑端看到的内容实时同步
- 🗣️ **社区页**：浏览大家在首页分享的内容并一键点赞；点资源名称可展开封面预览图（点图看大图），点「查看」直接跳转观看，自己的评论也能一键分享到社区
- 🔔 **互动提醒**：被 @、被回复、被点赞都会收到手机通知栏提醒，导航栏显示未读绿点；支持单条已读、全部已读与全部清除；资源可展开封面预览并一键「查看」跳转，封面加载失败会自动刷新重试（不再出现「点一下就收起」）；**退出软件后依然能收到**
- 🎨 **外观主题**：可跟随系统，也可自由切换日间 / 暗夜模式与 48 种主题色，界面即时生效
- 🧹 **数据管理**：可分别「清空缓存」或「清空全部数据」，释放空间、排除异常；清理后软件自动关闭，重新打开即为干净状态；新版本启动时还会自动清理旧的安装包，不占空间
- ⚙️ **资源预览设置**：可让资源预览图「总是显示」（默认收起、点资源名展开）；收藏夹内可单独开启「总是显示收藏资源预览图」（默认开启，关闭后恢复点资源名展开）
- ⬆️ **应用内更新**：自动检查新版本、展示更新说明，软件内直接下载 → **SHA-256 校验** → 拉起系统安装器完成安装；下载失败可一键改用浏览器兜底；升级采用统一正式签名，可直接覆盖安装、保留数据
- 🧭 **一体化导航**：媒体 / 社区 / 互动 / 设置 四个标签页随手切换，切页时媒体页保持不重载


## 📋 系统要求

- **操作系统**：Android 11 及以上
- **运行内存**：建议 4GB 及以上
- **存储空间**：安装约 80MB，浏览缓存另需约 200MB 以上
- **网络**：需能连接 Kirara Server（观看视频建议使用 WiFi 或稳定网络）
- **Google 服务**：无需安装 Google 服务框架，国产手机可直接使用
- **机型**：支持主流 Android 手机与平板

## ⬇️ 安装与更新

1. 前往本仓库 **Releases** 页面下载最新安装包（`Kirara_Media_vX.X.X.apk`）
2. 在手机上允许「安装未知来源应用」后完成安装
3. 首次启动后登录 Kirara_Server 通行证，即可开始使用
4. 软件内置更新检查：发现新版本会展示更新说明，可在软件内直接下载并校验安装包，随后由系统安装器完成覆盖安装；下载异常时可改用浏览器下载

> 📦 **应用内安装说明**：首次使用应用内更新时，系统可能提示需要「允许安装未知应用」，允许一次即可；这是 Android 对非商店应用安装的常规安全限制，无法跳过确认。
> ✅ **覆盖升级保留数据**：自 0.9.3-beta 起使用统一的正式发布签名，**新版本可直接覆盖安装**，登录状态、令牌与设置等本地数据自动保留，无需卸载。
> 🧹 **旧安装包自动清理**：新版本首次启动时会自动清理先前下载的安装包，无需手动处理。
> ⚠️ 仅当手机上装过**其它来源的旧版本**（例如早期测试调试包，签名不一致）时，才需要先卸载再安装；卸载会清除本地数据。

## 🚀 快速开始

### 三步上手

```
① 登录 KIRARA 通行证  →  ② 链接令牌  →  ③ 打开媒体页自动登录
```

1. **登录通行证**：输入 Kirara_Server 账号密码；勾选「记住登录」后，以后打开软件会自动进入，无需重复输入
2. **链接令牌**：两种方式任选——
   - **扫码导入**：在桌面端「令牌管理器」点该令牌右侧的扫码按钮，弹出动态二维码，再用手机扫码页对准扫描即可自动导入；
   - **手动录入**：在手机「设置 → 令牌管理器」手动填写媒体账户令牌。
   媒体页登录界面右下角的 **「链接令牌」圆点**也可直接触发自动登录
3. **一键直达**：进入「媒体」标签页，软件会自动完成登录并停在 Kirara Media 首页，直接开始使用

> 💡 登录遇到问题时不着急：软件会告诉你具体原因（如网络、密码或验证码），并提供重试 / 去设置 / 关闭三个入口，页面也随时可以手动登录。
> 📡 扫码导入时请让手机与桌面端处于同一网络，并注意桌面端二维码约每 15 秒刷新一次，请在图案刷新后尽快扫描。

### 常用操作

- **媒体浏览**：在视频详情页点右下角按钮即可打开评论区，标题栏会自动显示视频名称
- **评论区**：发表评论、回复、点赞、@好友；输入 `@` 即可从好友列表中挑选
- **社区页**：浏览首页分享并点赞；点资源名称展开封面预览（点图可看大图），点「查看」跳回媒体页观看
- **我的收藏**：收藏的视频默认展开预览图（可在「设置 → 资源预览」中关闭「总是显示收藏资源预览图」），点图看大图、点「查看」直达；点资源名称可收起
- **沉浸观看**：播放中旋转为横屏自动进入全屏；双击 / 误触不会退出全屏，按系统返回键退出全屏但继续播放；离开媒体页自动暂停
- **互动页**：查看被 @、被回复、被点赞的提醒；支持已读、全部已读、全部清除；有新消息时导航栏显示绿点；封面加载失败会自动刷新
- **软件更新**：在「设置 → 软件更新」检查新版本，软件内下载校验后直接安装；首次安装需允许一次「安装未知应用」
- **数据管理**：清空缓存或清空全部数据（清理后软件自动关闭，重新打开即为全新状态）
- **通知优化设置**：「后台保持设置」引导你将本应用加入系统电池优化白名单，「自动启动」引导开启自启动，让消息更及时

核心设计：

- **与电脑端体验一致**：媒体界面和操作习惯与电脑端保持一致，登录方式、评论内容、分享内容都是同一套，手机与电脑无缝衔接
- **扫码导入更省心**：无需手动抄录一长串令牌，扫码即自动识别、校验归属并落盘；仅属主账户可导入，安全又便捷
- **一次配置，长期免密**：登录状态会自动续期；出于安全考虑，换手机或重装应用后需要重新登录
- **失败也不添乱**：自动登录只在确认安全时提交，遇到验证码、网络异常等情况会如实告知并交还控制权，绝不反复尝试或误填
- **更新安全可校验**：应用内下载的安装包在安装前会进行完整性校验（SHA-256 等），校验不通过会拒绝安装并提示，避免装到损坏或被篡改的文件
- **消息不易错漏**：软件退出期间收到的互动消息，会在下次打开或系统唤醒时补充送达，尽量不让你错过
- **隐私优先**：令牌等敏感信息加密保存在应用内部，其他应用和文件管理器都无法读取；密码等敏感内容不会出现在任何日志中
- **安静省电**：后台不使用常驻通知，通知栏里只出现真正的新消息，不会多出"正在运行"之类的提示

## ❓ 常见问题

<details>
<summary><b>扫码导入提示失败 / 拒绝导入？</b></summary>

扫码导入时手机登录的 KIRARA 账户必须与导出令牌的桌面端账户一致——令牌只能导入到其所属账户，非本人令牌会被拒绝。另外桌面端二维码约每 15 秒自动更新，若遇到「二维码已过期」请等待桌面端图案刷新后立即重扫，并保持桌面端扫码窗口打开。
</details>

<details>
<summary><b>应用内更新提示需要「安装未知应用」权限？</b></summary>

这是 Android 对非应用商店来源安装的正常安全限制，无法跳过确认。首次使用应用内更新时，请在弹出的系统界面中允许「安装未知应用」，允许一次后即可正常安装；之后如想管理该权限，可在「系统设置 → 应用 → 本应用 → 安装未知应用」中随时开启或关闭。
</details>

<details>
<summary><b>应用内下载更新失败怎么办？</b></summary>

下载过程中会校验文件完整性（SHA-256 等），若因网络波动、下载源限制或文件损坏导致失败，弹窗会给出「重试」与「浏览器下载」两个入口：可先重试；若仍失败，改用浏览器下载安装包后手动安装即可，效果相同（均为同一正式签名包）。
</details>

<details>
<summary><b>退到后台一段时间后收不到消息？</b></summary>

部分国产系统在应用退到后台后会限制其联网，导致消息通道断开（这段时间的消息会在下次联网时补齐送达）。
可在「设置 → 通知优化设置」中点击「后台保持设置」，将本应用加入系统电池优化白名单；或点击「自动启动」开启自启动。这样消息会更及时。
</details>

<details>
<summary><b>消息为什么可能延迟十几分钟？</b></summary>

为了让通知栏保持干净（不出现"正在后台运行"之类的常驻通知），软件不会长期驻留后台。当系统回收应用后，会改为定期唤醒补发消息，因此最坏延迟约 15 分钟。应用在运行期间（含切到后台），消息都是实时到达的。
</details>

<details>
<summary><b>网络异常时还能使用吗？</b></summary>

浏览媒体本身需要联网。网络不稳定时，页面加载失败会给出提示并支持重试；@好友列表、评论与消息会在网络恢复后重新加载。
</details>

<details>
<summary><b>令牌/数据存在哪里？</b></summary>

所有数据都保存在应用内部，令牌等敏感信息已加密，其他应用与文件管理器都无法读取；卸载应用即全部清除。
如需重置，可在「设置 → 数据管理」中选择「清空全部数据」（会一并清除登录状态与令牌，需要重新登录）。
</details>

<details>
<summary><b>安装时提示与已装版本冲突？</b></summary>

说明手机上已装过其他来源的旧版本（例如早期测试调试包，与正式签名不一致）。请先卸载旧版本再安装新版本；自 0.9.3-beta 起的正式签名包之间可直接覆盖升级，数据自动保留。
</details>

<details>
<summary><b>视频全屏或旋转时体验异常？</b></summary>

播放视频时旋转为横屏会自动进入全屏并隐藏系统栏；全屏期间双击 / 误触不会退出全屏，按系统返回键会退出全屏但视频继续播放（不中断）；离开媒体页（切到其他标签页或退出）会自动暂停播放，回到媒体页不会自动续播。若遇到异常，可先退出全屏、转回竖屏后重试。
</details>
