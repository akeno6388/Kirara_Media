# Kirara_Media

> 一款 Kirara Media 的手机客户端，让你在手机上畅快观看媒体、参与议题讨论、与好友互动。
> 通过 **KIRARA 通行证登录 → 链接令牌 → 打开媒体页** 三步，一次配置，之后自动登录、免密直达。

## ✨ 功能特性

- 🔐 **一次登录，长期免密**：登录一次通行证，之后每次打开软件自动进入，无需反复输入账号密码
- 🔑 **令牌管理器**：集中保管你的媒体账户令牌，支持手动录入与扫码导入；令牌加密保存，仅本机可读
- 📷 **扫码导入令牌**：配合桌面端「令牌管理器」的扫码出码，手机相机扫码即可将令牌安全导入；桌面端二维码每 15 秒自动更新，令牌经加密传输，仅属主账户可导入；相机权限被拒时可一键跳转系统设置开启，系统返回键可直接退出扫码页
- 🖥️ **媒体随行**：在手机上完整使用 Kirara Media —— 浏览片库、查看详情、观看视频，画面与操作与电脑端一致
- 🎬 **沉浸式横屏播放**：播放视频时旋转为横屏会自动进入全屏并收起系统栏；全屏期间双击 / 误触不会退出全屏，按系统返回键 = 退出全屏但**视频继续播放**（不暂停）；离开媒体页自动暂停播放，切回不会自动续播
- 🤖 **自动登录**：打开媒体页自动完成登录；已登录时智能跳过。遇到问题会**如实说明原因**——例如断网时登录页会提示「网络请求失败，请检查网络连接」，而不是默默退回登录页；也可随时手动登录；服务器进入**通知 / 维护页**时，右下角按钮会变为「刷新」，处理完通知点一下即可重新加载判断是否恢复；宿舍/校园网弹出「访问被拒绝 / 站点已封锁」这类**网关拦截页**时，会**立刻把拦截页原样显示出来**（不再先空转转圈等待），可直接在页面上完成认证
- 🧾 **登录账号记忆**：登录过的用户名、AD 域账户与邮箱都会被记住，下次点输入框右侧按钮即可从历史列表中一键选择，也能逐条删除；**只记账号，绝不保存密码**
- 📧 **邮箱验证码登录**：除通行证与 AD 域外还支持邮箱验证码登录；**关闭软件重开时**邮箱框不预填，历史邮箱从右侧列表选取；点击「获取验证码」后按钮会**立即**变灰并显示「正在获取验证码...」，不会让人以为界面卡住；验证码输错会明确提示**「验证码错误」**（不再误报成"用户名或密码错误"）
- 🔒 **退出即清空 + 回到原界面**：退出登录回到登录页后，上一会话的**验证码与所有密码都会清空**，并直接回到上次用的那种登录方式的界面（邮箱登录会把邮箱填回并解除锁定，可直接重新获取验证码；「保存账号」勾选保留）
- 💬 **议题评论**：视频详情页一键打开评论区，支持发表评论、回复、点赞与 @好友；@片段以主题色高亮，**任何账号看到的高亮效果一致**（修复：他人视角曾不变色）；**回复不再弹出小输入框**——点评论/回复右侧的「回复」后，直接复用底部输入栏输入（顶部显示「回复 某某」，输入框内不再重复提示，键盘自动弹出，再点一次同一按钮或点 ✕ 即退出），@ 按钮（选人、退格整体删除 @ 字段等完整能力）在回复时同样可用，@ 列表**包含自己**（@ 自己不会收到推送提醒）；与电脑端看到的内容实时同步
- 🔐 **隐私提及**：点「@」选人时，列表下方可勾选「隐私提及」——这条评论及其下属全部回复**只对你自己和被 @ 的人可见**，其他人完全看不到（如同不存在）；被 @ 的人照常收到互动提醒，你也能在「我的最近评论」里找到它。评论前会标出「隐私评论：」前缀，输入栏上方出现隐私提示条可随时取消，同时「分享到首页」按钮隐藏，避免私密内容被分享出去；隐私楼内回复时 @ 按钮会置灰（楼层可见范围在发出时就已固定，不能再拉新人进来）
- 💡 **提示条平滑出入**：回复提示条、隐私提示条与输入错误提示出现/消失时不再硬切，而是**淡入淡出并带着高度展开 / 收拢**，输入框被轻柔地推下或回位，打字时界面不会上下跳一下
- ⚡ **来回跳转不再越跳越慢**：在社区 / 互动点「查看」现在是**站内切换、不再整页重新加载**，从社区看一个资源、立刻再跳下一个也不会一次比一次慢；连续快速点「查看」只会保留最后一次目标、不会排队堆叠，站内切换没生效时（例如被网关拦截）自动退回普通加载，不会白点
- 🏷️ **标题永远对得上**：评论区标题栏与收藏里的资源名直接由服务端给出，跳转过渡期间**不会再显示上一个资源的名字、也不会退回成 "Jellyfin" 这类站点名**；看过的资源标题走内存缓存，来回切换零等待、不再占网络，此前「收藏条目显示成原始资源链接」的问题随之消失
- 📊 **互动数字一目了然**：点赞数超过 999 后自动收成 `1.2K` / `50.7K` / `1.3M` 这种短写法，不再撑宽条目；评论区同一行里「回复」按钮的位置固定不动，上下条目的红心也整整齐齐对齐
- 📖 **长内容完整可读**：互动条目、资源名、媒体库标签等位置**一率换行完整显示**，容器向下长高适配，不再出现「…」截断；点按资源名时高亮的是**整个圆角容器**（不再套一圈直角方框）
- 🗂️ **评论分层卡片**：主评论是独立卡片，回复收在卡片内更小一级的子卡片里（带描边区分），「回复的回复」会标出「回复 某某：」并排在对应回复下方，一眼能分清谁在回谁；长评论列表不再靠分割线堆在一起
- ⌨️ **@ 选人更顺手**：键盘打开时点「@」，键盘会平滑收起、选人面板几乎同时弹出，不会再出现键盘突然消失或空等；选完人确认后键盘自动弹回，可以接着打字
- 🗣️ **社区页**：浏览大家在首页分享的内容并一键点赞；点资源名称可展开封面预览图（点图看大图、**可双指放大**），点「查看」直接跳转观看，自己的评论也能一键分享到社区；「**我的最近评论**」里能按时间看到**我自己发过的评论、回复（含「回复某某」的回复的回复）与分享**——回复条目带「回复」小标签，一眼能和评论区分开；互动条目里的资源名同样显示解析出的资源名（不再统一占位成「资源预览」）
- ✨ **点赞 / 收藏特效**：点赞时红心会先「压一下再弹起」并迸出粒子（两圈扩散光环 + 8 颗小红点逐个错开飞出），计数稍晚轻跳一下；详情页点亮收藏金星同样弹跳 + 轻微摇摆，并炸出金色粒子（光环 + 圆点 + 会转的星屑）。取消点赞 / 收藏只做一次安静的回收，不炸粒子；进入一个「本来就已收藏」的视频不会误放特效
- 🔔 **互动提醒**：**只接收本应用相关的互动——媒体议题 + 催更**——被 @、被回复、被点赞，以及**催更被点赞 / 管理员已读（审批完成）**都会收到手机通知栏提醒，导航栏显示未读绿点；支持单条已读、全部已读与全部清除（删除条目带**滑出 + 淡出 + 下方条目平滑补位**的动效）；资源可展开封面预览并一键「查看」跳转，封面加载失败会自动刷新重试（不再出现「点一下就收起」）；**退出软件后依然能收到**。系统广播 / 服务通知、社区首页分享的互动与本应用无关，不再混进互动区（桌面端通知中心仍然全局接收）
- 🎨 **外观主题**：可跟随系统，也可自由切换日间 / 暗夜模式与 48 种主题色，界面即时生效
- 🖼️ **更换头像**：设置页账户信息卡片右侧的「编辑」按钮点一下，卡片即向下展开露出「更换头像」按钮（也可以**直接点头像**）；选好图片自动居中裁成正方形后**先弹出效果预览确认弹窗**（GIF 动图保留动画，预览为首帧），点「确认上传」才会真正上传，取消则不上传；换完**所有页面**的头像立刻更新，无需重启
- ✏️ **修改昵称**：同样在账户卡展开区，「更换头像」旁边的「修改昵称」按钮点开弹窗即可改显示昵称（登录用户名不变）；保存后账户卡显示名立即更新，无需重新登录
- 🧹 **数据管理**：可分别「清空缓存」或「清空全部数据」，释放空间、排除异常；「清空全部数据」会一并清掉**登录页记住的账号**与外观设置等全部用户数据（等同全新安装），清理后软件自动关闭，重新打开即为干净状态；新版本启动时还会自动清理旧的安装包，不占空间
- ⚙️ **资源预览设置**：可让资源预览图「总是显示」（默认收起、点资源名展开）；收藏夹内可单独开启「总是显示收藏资源预览图」（默认开启，关闭后恢复点资源名展开）——两项都在「**设置 → 外观与个性化**」内（原独立的「资源预览」分区已并入）
- 💭 **评论区自动展开**（设置项，默认**开启**）：开启后从社区/互动点「查看」跳转到资源页面时**评论区会自动展开**；关闭后跳转只打开页面、评论区保持折叠，需要时点右下角「评论」按钮手动展开（「我的收藏」的「查看」始终不展开评论区）
- ⬆️ **应用内更新**：自动检查新版本、展示更新说明，软件内直接下载 → **SHA-256 校验** → 拉起系统安装器完成安装；跳过好几个版本时，更新说明会**按版本号逐个列出你错过的每一版做了什么**，中途若有一版是「重要更新」也不会被忽略；下载失败可一键改用浏览器兜底；升级采用统一正式签名，可直接覆盖安装、保留数据
- 🚀 **品牌开屏**：冷启动先显示品牌图标开屏（**至少 1 秒**），再自动进入登录页或主界面；全新安装、断网、自动登录成功/失败各路径都会出现（0.9.9-beta 及以前在无凭据路径下开屏会完全不显示，已修复）
- 🧭 **一体化导航**：媒体 / 社区 / 互动 / 设置 四个标签页随手切换，切页时媒体页保持不重载


## 📋 系统要求

- **操作系统**：Android 11 及以上
- **运行内存**：建议 4GB 及以上
- **存储空间**：安装约 80MB，浏览缓存另需约 200MB 以上
- **网络**：需能连接 Kirara Server（观看视频建议使用 WiFi 或稳定网络）
- **Google 服务**：无需安装 Google 服务框架，国产手机可直接使用
- **机型**：支持主流 Android 手机与平板

## ⬇️ 安装与更新

1. 前往本仓库 **Releases** 页面下载最新安装包（`Kirara_Media_vX.X.X.apk`）
2. 在手机上允许「安装未知来源应用」后完成安装
3. 首次启动后登录 Kirara_Server 通行证，即可开始使用
4. 软件内置更新检查：发现新版本会展示更新说明，可在软件内直接下载并校验安装包，随后由系统安装器完成覆盖安装；下载异常时可改用浏览器下载

> 📦 **应用内安装说明**：首次使用应用内更新时，系统可能提示需要「允许安装未知应用」，允许一次即可；这是 Android 对非商店应用安装的常规安全限制，无法跳过确认。
> ✅ **覆盖升级保留数据**：自 0.9.3-beta 起使用统一的正式发布签名，**新版本可直接覆盖安装**，登录状态、令牌与设置等本地数据自动保留，无需卸载。
> 🧹 **旧安装包自动清理**：新版本首次启动时会自动清理先前下载的安装包，无需手动处理。
> ⚠️ 仅当手机上装过**其它来源的旧版本**（例如早期测试调试包，签名不一致）时，才需要先卸载再安装；卸载会清除本地数据。

## 🚀 快速开始

### 三步上手

```
① 登录 KIRARA 通行证  →  ② 链接令牌  →  ③ 打开媒体页自动登录
```

1. **登录通行证**：输入 Kirara_Server 账号密码；勾选「记住登录」后，以后打开软件会自动进入，无需重复输入
2. **链接令牌**：两种方式任选——
   - **扫码导入**：在桌面端「令牌管理器」点该令牌右侧的扫码按钮，弹出动态二维码，再用手机扫码页对准扫描即可自动导入；
   - **手动录入**：在手机「设置 → 令牌管理器」手动填写媒体账户令牌（**令牌名称为必填项**；录入成功后可点「**更改名称**」随时改名，与「清除令牌」并排各占半列）。
   媒体页登录界面右下角的 **「链接令牌」圆点**也可直接触发自动登录
3. **一键直达**：进入「媒体」标签页，软件会自动完成登录并停在 Kirara Media 首页，直接开始使用

> 💡 登录遇到问题时不着急：软件会告诉你具体原因（如网络、密码或验证码），并提供重试 / 去设置 / 关闭三个入口，页面也随时可以手动登录。
> 📡 扫码导入时请让手机与桌面端处于同一网络，并注意桌面端二维码约每 15 秒刷新一次，请在图案刷新后尽快扫描。

### 常用操作

- **媒体浏览**：在视频详情页点右下角按钮即可打开评论区，标题栏会自动显示视频名称；旁边的「收藏」按钮星星更大、填充色与评论按钮一致（点金黄色实心星即已收藏）
- **评论区**：发表评论、回复、点赞、@好友；输入 `@` 或点输入框右侧 @ 按钮即可从用户列表中挑选（**含自己**，@ 自己不推送通知；选中的 @片段以主题色高亮，任何人看到的效果一致）；回复某条回复会自动带上 `@对方昵称` 前缀，退格一并整体删除
- **社区页**：浏览首页分享并点赞；点资源名称展开封面预览（点图可看大图、**支持双指放大与拖动查看**），点「查看」跳回媒体页观看；「我的最近评论」按时间汇总**我发过的评论 + 回复 + 分享**（回复条目带「回复」标签，「回复的回复」还会显示「回复某某：」）
- **我的收藏**：收藏的视频默认展开预览图（可在「设置 → 外观与个性化」中关闭「总是显示收藏资源预览图」），点图看大图、点「查看」直达；点资源名称可收起
- **沉浸观看**：播放中旋转为横屏自动进入全屏；双击 / 误触不会退出全屏，按系统返回键退出全屏但继续播放；离开媒体页自动暂停
- **互动页**：查看被 @、被回复、被点赞的提醒；支持已读、全部已读、全部清除；有新消息时导航栏显示绿点；封面加载失败会自动刷新
- **软件更新**：在「设置 → 软件更新」检查新版本，软件内下载校验后直接安装；首次安装需允许一次「安装未知应用」
- **数据管理**：清空缓存或清空全部数据（清理后软件自动关闭，重新打开即为全新状态；「清空全部数据」连登录页记住的账号一并清除）
- **通知优化设置**：「后台优化策略」一键跳到**你手机品牌**的省电/电池策略页（设为「无限制」），「自动启动」一键跳到该品牌的**自启动管理页**，让消息更及时
- **更换头像**：设置页账户卡点「编辑」展开后点「更换头像」，或**直接点头像**；选中图片会自动居中裁成正方形（GIF 保留动画）并弹出**效果预览确认弹窗**，点「确认上传」才真正上传（取消不上传）；换完各页面头像立即更新
- **修改昵称**：设置页账户卡点「编辑」展开后点「更换头像」旁的「修改昵称」，输入新昵称保存即可（登录用户名不变；仅限 1-16 个字符、不含特殊符号）；保存后账户卡显示名立即更新

核心设计：

- **与电脑端体验一致**：媒体界面和操作习惯与电脑端保持一致，登录方式、评论内容、分享内容都是同一套，手机与电脑无缝衔接
- **扫码导入更省心**：无需手动抄录一长串令牌，扫码即自动识别、校验归属并落盘；仅属主账户可导入，安全又便捷
- **一次配置，长期免密**：登录状态会自动续期；出于安全考虑，换手机或重装应用后需要重新登录
- **失败也不添乱**：自动登录只在确认安全时提交，遇到验证码、网络异常等情况会如实告知并交还控制权，绝不反复尝试或误填
- **更新安全可校验**：应用内下载的安装包在安装前会进行完整性校验（SHA-256 等），校验不通过会拒绝安装并提示，避免装到损坏或被篡改的文件
- **消息不易错漏**：软件退出期间收到的互动消息，会在下次打开或系统唤醒时补充送达，尽量不让你错过
- **隐私优先**：令牌等敏感信息加密保存在应用内部，其他应用和文件管理器都无法读取；密码等敏感内容不会出现在任何日志中
- **安静省电**：后台不使用常驻通知，通知栏里只出现真正的新消息，不会多出"正在运行"之类的提示

## ❓ 常见问题

<details>
<summary><b>扫码导入提示失败 / 拒绝导入？</b></summary>

扫码导入时手机登录的 KIRARA 账户必须与导出令牌的桌面端账户一致——令牌只能导入到其所属账户，非本人令牌会被拒绝。另外桌面端二维码约每 15 秒自动更新，若遇到「二维码已过期」请等待桌面端图案刷新后立即重扫，并保持桌面端扫码窗口打开。
</details>

<details>
<summary><b>应用内更新提示需要「安装未知应用」权限？</b></summary>

这是 Android 对非应用商店来源安装的正常安全限制，无法跳过确认。首次使用应用内更新时，请在弹出的系统界面中允许「安装未知应用」，允许一次后即可正常安装；之后如想管理该权限，可在「系统设置 → 应用 → 本应用 → 安装未知应用」中随时开启或关闭。
</details>

<details>
<summary><b>应用内下载更新失败怎么办？</b></summary>

下载过程中会校验文件完整性（SHA-256 等），若因网络波动、下载源限制或文件损坏导致失败，弹窗会给出「重试」与「浏览器下载」两个入口：可先重试；若仍失败，改用浏览器下载安装包后手动安装即可，效果相同（均为同一正式签名包）。
</details>

<details>
<summary><b>退到后台一段时间后收不到消息？</b></summary>

部分国产系统在应用退到后台后会限制其联网，导致消息通道断开（这段时间的消息会在下次联网时补齐送达）。
可在「设置 → 通知优化设置」中点击「后台优化策略」右侧的「设置」，把本应用的省电策略改为「无限制」；再点「自动启动」右侧的「设置」，打开本应用的自启动开关。这样消息会更及时。

这两处会按键（小米/红米、华为、荣耀、OPPO/一加/realme、vivo/iQOO、魅族、三星等）自动跳到对应的系统设置页；
若某个机型确实找不到厂商页面，会退回「应用信息」页并给出提示。
</details>

<details>
<summary><b>断网时打开软件，为什么回到了登录界面？</b></summary>

勾选「记住登录」后，软件启动时会自动尝试登录。**没有网络时这次尝试必然失败，因此会回到登录界面**——这是正常的，此时登录页会明确提示「网络请求失败，请检查网络连接」（超时则提示「网络连接超时，请检查网络后重试」）。

- 你的登录凭据**不会被清除**，恢复网络后重新打开软件即可自动登录，无需重新输入密码
- 若提示的是「用户名或密码错误」之类的文案，才说明凭据已失效，需要重新登录
</details>

<details>
<summary><b>登录页的用户名怎么快速填？密码框为什么是空的？</b></summary>

**账号记忆**：成功登录过的用户名、AD 域账户与邮箱都会被记住，输入框右侧会出现历史按钮，点击即可从列表中选择，列表里每一项右侧的小叉可以删除该条记录。出于安全考虑，这里**只记账号，不保存密码**。

**退出登录会被清成什么样**：回到登录页时，上一会话的**验证码和所有密码都会清空**，并**直接回到你上次用的那种登录方式的界面**，把**账号名**放回输入框——邮箱登录还会把**邮箱一并填回并解除锁定**（可以直接重新获取验证码）。

**关闭软件重开时**：用户名与 AD 域账户会预填上次用过的那个，**邮箱不会预填**（为免误导），请从邮箱框右侧的历史按钮里选。

**密码框为空是正常的**：主动退出登录（或被顶号、改密码强退）后回到登录页，密码框会自动清空，避免上一位使用者的输入残留；「保存账号」勾选仍会保留。只有登录**失败**时密码才会留在框里，方便你改一位后重试。
</details>

<details>
<summary><b>消息为什么可能延迟十几分钟？</b></summary>

为了让通知栏保持干净（不出现"正在后台运行"之类的常驻通知），软件不会长期驻留后台。当系统回收应用后，会改为定期唤醒补发消息，因此最坏延迟约 15 分钟。应用在运行期间（含切到后台），消息都是实时到达的。
</details>

<details>
<summary><b>网络异常时还能使用吗？</b></summary>

浏览媒体本身需要联网。网络不稳定时，页面加载失败会给出提示并支持重试；@好友列表、评论与消息会在网络恢复后重新加载。
</details>

<details>
<summary><b>令牌/数据存在哪里？</b></summary>

所有数据都保存在应用内部，令牌等敏感信息已加密，其他应用与文件管理器都无法读取；卸载应用即全部清除。
如需重置，可在「设置 → 数据管理」中选择「清空全部数据」（会一并清除登录状态、令牌、**登录页记住的账号**与外观设置，需要重新登录）。
</details>

<details>
<summary><b>安装时提示与已装版本冲突？</b></summary>

说明手机上已装过其他来源的旧版本（例如早期测试调试包，与正式签名不一致）。请先卸载旧版本再安装新版本；自 0.9.3-beta 起的正式签名包之间可直接覆盖升级，数据自动保留。
</details>

<details>
<summary><b>视频全屏或旋转时体验异常？</b></summary>

播放视频时旋转为横屏会自动进入全屏并隐藏系统栏；全屏期间双击 / 误触不会退出全屏，按系统返回键会退出全屏但视频继续播放（不中断）；离开媒体页（切到其他标签页或退出）会自动暂停播放，回到媒体页不会自动续播。若遇到异常，可先退出全屏、转回竖屏后重试。
</details>
