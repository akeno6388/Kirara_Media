# Kirara_Media

> 一款 Kirara Media 的手机客户端，让你在手机上畅快观看媒体、参与议题讨论、与好友互动。
> 通过 **KIRARA 通行证登录 → 链接令牌 → 打开媒体页** 三步，一次配置，之后自动登录、免密直达。

## ✨ 功能特性

- 🔐 **一次登录，长期免密**：登录一次通行证，之后每次打开软件自动进入，无需反复输入账号密码
- 🔑 **令牌管理器**：集中保管你的媒体账户令牌，支持手动录入与扫码导入（规划中）；令牌加密保存，仅本机可读
- 🖥️ **媒体随行**：在手机上完整使用 Kirara Media —— 浏览片库、查看详情、观看视频，画面与操作与电脑端一致
- 🎬 **全屏播放不断播**：视频支持全屏观看；播放中横竖屏切换会保留播放进度，不会退回首页
- 🤖 **自动登录**：打开媒体页自动完成登录；已登录时智能跳过，遇到问题会说明原因并可一键重试，也可随时手动登录
- 💬 **议题评论**：视频详情页一键打开评论区，支持发表评论、回复、点赞与 @好友；与电脑端看到的内容实时同步
- 🗣️ **社区页**：浏览大家在首页分享的内容并一键点赞；看到感兴趣的资源可直接跳转观看，自己的评论也能一键分享到社区
- 🔔 **互动提醒**：被 @、被回复、被点赞都会收到手机通知栏提醒，导航栏显示未读绿点；支持单条已读、全部已读与全部清除；**退出软件后依然能收到**
- 🎨 **外观主题**：可跟随系统，也可自由切换日间 / 暗夜模式与 48 种主题色，界面即时生效
- 🧹 **数据管理**：可分别「清空缓存」或「清空全部数据」，释放空间、排除异常；清理后软件自动关闭，重新打开即为干净状态
- ⬆️ **应用内更新**：自动检查新版本，查看更新说明并直接下载安装
- 🧭 **一体化导航**：媒体 / 社区 / 互动 / 设置 四个标签页随手切换，切页时媒体页保持不重载


## 📋 系统要求

- **操作系统**：Android 11 及以上
- **运行内存**：建议 4GB 及以上
- **存储空间**：安装约 60MB，浏览缓存另需约 30MB 以上
- **网络**：需能连接 Kirara Server（观看视频建议使用 WiFi 或稳定网络）
- **Google 服务**：无需安装 Google 服务框架，国产手机可直接使用
- **机型**：支持主流 Android 手机与平板

## ⬇️ 安装与更新

1. 前往本仓库 **Releases** 页面下载最新安装包（`Kirara_Media_vX.X.X.apk`）
2. 在手机上允许「安装未知来源应用」后完成安装
3. 首次启动后登录 Kirara_Server 通行证，即可开始使用
4. 软件内置更新检查，可展示版本说明并引导下载安装新版本

> ⚠️ 若手机上装过旧版本，请先卸载再安装新版本（卸载会清除本地数据，需要重新登录通行证并重新录入令牌）。


## 🚀 快速开始

### 三步上手

```
① 登录 KIRARA 通行证  →  ② 链接令牌  →  ③ 打开媒体页自动登录
```

1. **登录通行证**：输入 Kirara_Server 账号密码；勾选「记住登录」后，以后打开软件会自动进入，无需重复输入
2. **链接令牌**：在「设置 → 令牌管理器」录入（或扫码导入）媒体账户令牌；媒体页登录界面右下角的 **「链接令牌」圆点**也可直接触发自动登录
3. **一键直达**：进入「媒体」标签页，软件会自动完成登录并停在 Kirara Media 首页，直接开始使用

> 💡 登录遇到问题时不着急：软件会告诉你具体原因（如网络、密码或验证码），并提供重试 / 去设置 / 关闭三个入口，页面也随时可以手动登录。

### 常用操作

- **媒体浏览**：在视频详情页点右下角按钮即可打开评论区，标题栏会自动显示视频名称
- **评论区**：发表评论、回复、点赞、@好友；输入 `@` 即可从好友列表中挑选
- **社区页**：浏览首页分享并点赞；点资源标题可直接跳回媒体页观看
- **互动页**：查看被 @、被回复、被点赞的提醒；支持已读、全部已读、全部清除；有新消息时导航栏显示绿点
- **数据管理**：清空缓存或清空全部数据（清理后软件自动关闭，重新打开即为全新状态）
- **通知优化设置**：「后台保持设置」引导你将本应用加入系统电池优化白名单，「自动启动」引导开启自启动，让消息更及时

核心设计：

- **与电脑端体验一致**：媒体界面和操作习惯与电脑端保持一致，登录方式、评论内容、分享内容都是同一套，手机与电脑无缝衔接
- **一次配置，长期免密**：登录状态会自动续期；出于安全考虑，换手机或重装应用后需要重新登录
- **失败也不添乱**：自动登录只在确认安全时提交，遇到验证码、网络异常等情况会如实告知并交还控制权，绝不反复尝试或误填
- **消息不易错漏**：软件退出期间收到的互动消息，会在下次打开或系统唤醒时补充送达，尽量不让你错过
- **隐私优先**：令牌等敏感信息加密保存在应用内部，其他应用和文件管理器都无法读取；密码等敏感内容不会出现在任何日志中
- **安静省电**：后台不使用常驻通知，通知栏里只出现真正的新消息，不会多出"正在运行"之类的提示

## ❓ 常见问题

<details>
<summary><b>退到后台一段时间后收不到消息？</b></summary>

部分国产系统在应用退到后台后会限制其联网，导致消息通道断开（这段时间的消息会在下次联网时补齐送达）。
可在「设置 → 通知优化设置」中点击「后台保持设置」，将本应用加入系统电池优化白名单；或点击「自动启动」开启自启动。这样消息会更及时。
</details>

<details>
<summary><b>消息为什么可能延迟十几分钟？</b></summary>

为了让通知栏保持干净（不出现"正在后台运行"之类的常驻通知），软件不会长期驻留后台。当系统回收应用后，会改为定期唤醒补发消息，因此最坏延迟约 15 分钟。应用在运行期间（含切到后台），消息都是实时到达的。
</details>

<details>
<summary><b>网络异常时还能使用吗？</b></summary>

浏览媒体本身需要联网。网络不稳定时，页面加载失败会给出提示并支持重试；@好友列表、评论与消息会在网络恢复后重新加载。
</details>

<details>
<summary><b>令牌/数据存在哪里？</b></summary>

所有数据都保存在应用内部，令牌等敏感信息已加密，其他应用与文件管理器都无法读取；卸载应用即全部清除。
如需重置，可在「设置 → 数据管理」中选择「清空全部数据」（会一并清除登录状态与令牌，需要重新登录）。
</details>

<details>
<summary><b>安装时提示与已装版本冲突？</b></summary>

说明手机上已装过其他来源的旧版本（例如早期测试包）。请先卸载旧版本再安装新版本；卸载会清除本地数据，需要重新登录通行证并重新录入令牌。
</details>

<details>
<summary><b>视频全屏或旋转时体验异常？</b></summary>

视频支持全屏观看，全屏时可滑动唤出系统状态栏；播放中旋转手机会保留播放进度与当前页面，不会退回首页。
</details>
